В мобильной версии на ST7735 используется две версии дисплея.
Версии различаются двумя моментами:
1. Инверсия цвета.
2. Смещение по строкам и столбцам.
Выбор нужного типа дисплея осуществляется последним байтом области 8кБ, предназначенной
для загрузчика.
00 - старый тип дисплея (полностью чёрный экран)
FF - новый тип дисплея (синяя полоса с левого краю дисплея)
